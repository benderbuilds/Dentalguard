DentalPilot Widget Test Page

This page loads the chatbot widget for testing against a local dev server.

Setup

  1. Start the Next.js dev server: npm run dev (from the project root)
  2. Build the widget: cd widget && npm run build
  3. Replace YOUR_EMBED_KEY below with a real embed key from your chatbot_configs table
  4. Open this file in a browser (or use npx serve widget/)
